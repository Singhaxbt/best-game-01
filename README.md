NEON SURGE — a wave-based arena survival game: move with WASD, aim with the mouse, auto-fire at the swarm, collect XP gems, level up and pick upgrades, survive escalating waves and a boss every 5 waves. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC. Referral code: `cnrz2rkm`.

## Controls

- **WASD / Arrows** — move
- **Mouse** — aim (auto-fire is always on)
- **SPACE** — dash (brief invulnerability)
- **P / ESC** — pause / resume
- **1 / 2 / 3 or click** — pick a level-up upgrade card
- **ENTER / R / click** — start and restart
- **M** — mute

## Play

Serve `game/` with any static server and open `index.html` in desktop Chrome — no build step, no network. The swarm comes in waves: chasers, shooters, splitters, tanks, and the VOID MAW boss every 5th wave. Kills drop XP gems; level up to choose 1 of 3 upgrade cards (damage, fire rate, multishot, pierce, speed, max HP, magnet, dash cooldown). Chained kills build a combo multiplier up to +200% score. Your best score is kept in the browser.
